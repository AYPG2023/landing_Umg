# Tarea: Crear Landing Page para promocionar Ingeniería en Sistemas UMG

## Objetivo
Desarrollar una landing page moderna, responsiva y atractiva para promocionar la carrera de Ingeniería en Sistemas de la Universidad Mariano Gálvez.

## Tecnologías obligatorias
- HTML5
- Tailwind CSS
- JavaScript vanilla
- No usar frameworks como React, Angular o Vue

## Requerimientos principales

### 1. Estructura general
Crear una página `index.html` con las siguientes secciones:

- Navbar fijo o sticky
- Hero principal
- ¿Por qué estudiar Ingeniería en Sistemas?
- Áreas de aprendizaje
- Perfil del egresado
- Beneficios de estudiar en UMG
- Galería o sección visual
- Testimonios
- Formulario de contacto
- Footer

---

## 2. Diseño visual

La landing debe tener un diseño moderno, universitario y tecnológico.

Usar:
- Colores institucionales o similares: azul, blanco, gris y detalles dorados o celestes.
- Tipografía limpia y profesional.
- Cards con sombras suaves.
- Bordes redondeados.
- Animaciones sutiles al hacer scroll.
- Diseño 100% responsivo para móvil, tablet y escritorio.

---

## 3. Navbar

Debe incluir enlaces internos:

- Inicio
- Carrera
- Áreas
- Beneficios
- Contacto

El navbar debe:
- Ser responsivo.
- Tener menú hamburguesa en móvil.
- Hacer scroll suave a cada sección.
- Cambiar ligeramente al hacer scroll, por ejemplo con sombra o fondo más sólido.

---

## 4. Hero principal

Crear una sección inicial llamativa con:

- Título principal:
  “Estudia Ingeniería en Sistemas en UMG”

- Subtítulo:
  “Prepárate para crear software, administrar tecnología, resolver problemas reales y construir tu futuro profesional.”

- Botones:
    - “Solicitar información”
    - “Ver pensum”

- Imagen o ilustración relacionada con tecnología, programación, servidores, estudiantes o innovación.

---

## 5. Sección: ¿Por qué estudiar Ingeniería en Sistemas?

Crear una sección con texto breve y cards explicando:

- Alta demanda laboral.
- Oportunidad de trabajar remoto.
- Desarrollo de software.
- Administración de bases de datos.
- Ciberseguridad.
- Innovación tecnológica.

---

## 6. Áreas de aprendizaje

Crear cards o bloques para las áreas:

- Programación
- Bases de datos
- Redes
- Desarrollo web
- Inteligencia artificial
- Ciberseguridad
- Ingeniería de software
- Sistemas operativos

Cada card debe tener:
- Ícono o emoji tecnológico.
- Título.
- Descripción corta.

---

## 7. Perfil del egresado

Mostrar una sección profesional indicando que el egresado podrá:

- Diseñar y desarrollar sistemas informáticos.
- Administrar bases de datos.
- Implementar soluciones tecnológicas.
- Gestionar proyectos de software.
- Analizar procesos empresariales.
- Trabajar como desarrollador, analista, DBA, soporte técnico, DevOps o consultor tecnológico.

---

## 8. Beneficios de estudiar en UMG

Agregar una sección con beneficios:

- Formación académica sólida.
- Enfoque práctico.
- Docentes con experiencia.
- Oportunidades de crecimiento profesional.
- Modalidades accesibles.
- Comunidad universitaria.

---

## 9. Galería visual

Crear una sección con 3 o 4 imágenes usando URLs libres o placeholders relacionados con:

- Programación.
- Estudiantes.
- Tecnología.
- Laboratorios.

Las imágenes deben tener buen diseño, bordes redondeados y efecto hover.

---

## 10. Testimonios

Agregar 3 testimonios ficticios de estudiantes o egresados.

Cada testimonio debe tener:
- Nombre.
- Rol, por ejemplo “Estudiante de Ingeniería en Sistemas”.
- Comentario breve.
- Diseño tipo card.

---

## 11. Formulario de contacto

Crear un formulario con los campos:

- Nombre completo
- Correo electrónico
- Teléfono
- Jornada de interés
- Mensaje

Validaciones con JavaScript:
- No permitir campos vacíos.
- Validar correo electrónico.
- Mostrar mensaje de éxito si todo está correcto.
- Mostrar mensajes de error claros si falta información.

No es necesario enviar datos a backend.

---

## 12. JavaScript requerido

Crear un archivo `script.js` con:

- Menú hamburguesa funcional.
- Scroll suave.
- Validación del formulario.
- Animaciones al hacer scroll usando IntersectionObserver.
- Cambio de estilo del navbar al hacer scroll.
- Botón “volver arriba”.

---

landing-umg-sistemas/

14. README.md

Crear un README con:

Nombre del proyecto.
Descripción.
Tecnologías utilizadas.
Cómo ejecutar el proyecto.
Funcionalidades principales.
Capturas de pantalla opcionales.
Autor.
15. Criterios de calidad

El código debe estar:

Limpio.
Ordenado.
Comentado solo donde sea necesario.
Con nombres de clases y funciones claros.
Sin código repetido innecesario.
Optimizado para buena presentación visual.
Resultado esperado

Una landing page profesional, moderna y responsiva que promocione la carrera de Ingeniería en Sistemas de UMG, lista para presentarse como proyecto académico.
