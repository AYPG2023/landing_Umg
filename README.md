# Landing UMG Sistemas

Landing page moderna para promocionar la carrera de Ingenieria en Sistemas de la Universidad Mariano Galvez.

## Descripcion

El proyecto presenta una experiencia visual universitaria y tecnologica con enfoque responsivo. Incluye secciones informativas sobre la carrera, areas de aprendizaje, beneficios, testimonios, galeria y un formulario de contacto con validacion en frontend.

## Tecnologias utilizadas

- HTML5
- Tailwind CSS
- JavaScript vanilla
- CSS personalizado para detalles visuales y animaciones

## Como ejecutar el proyecto

1. Clona o descarga el proyecto.
2. Abre `index.html` en tu navegador.
3. No requiere backend ni proceso de compilacion.

## Funcionalidades principales

- Navbar sticky con cambio visual al hacer scroll
- Menu hamburguesa responsivo
- Scroll suave entre secciones
- Hero principal con llamados a la accion
- Secciones de carrera, areas, perfil, beneficios, galeria y testimonios
- Formulario de contacto con validacion de campos vacios y correo electronico
- Animaciones sutiles con `IntersectionObserver`
- Boton de volver arriba
